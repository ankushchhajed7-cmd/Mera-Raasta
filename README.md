# Mera Raasta

Apne record kiye raaston par GPS navigation — by Ankush New Vision.

- **Record:** map on karke chalo, har jagah (A, B, C, D) par "Yahan jagah save karo" dabao.
- **Chalo:** kahin se bhi kisi saved jagah ka sabse chhota raasta (sirf aapke recorded raaston par), Hindi awaaz ke saath.
- Installable PWA, offline cache, backup/restore.

Live: https://ankushchhajed7-cmd.github.io/Mera-Raasta/
